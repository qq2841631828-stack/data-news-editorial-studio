# 数据新闻编辑工作室

`data-news-editorial-studio` 是用于 Codex 的中文数据新闻 Skill，当前版本为 **3.1.0**。

它把选题、来源核验、叙事、图表设计、视觉生产和交付检查组织为一个可复用流程。支持连续长图、单张大海报以及网页/H5 形式；交互产品需要另行落实和验证网页实现。

长图与海报新增优先制作流程：**Image-2 视觉草案/素材 → SVG 真实对象编排 → 可画导入与编辑验收 → 高清成品**。AI 负责视觉表现，文字和数据图形按核验后的内容重建；SVG 不是整张 PNG 的文件包装。

**v3.1.0 验证状态（2026-10-06）：本地母版与导入文件已验证，完整作品的可画验收待完成。** 本次按仓库所有者要求发布这版更新，不把发布状态等同于目标平台验收通过。之前的骑行演示已验证可画中国版1024×5120单页与2160×10800导出；新AI专题不能沿用旧小样的验收结论。当前自动上传受到连接浏览器的文件URL权限限制。

已检查本地渲染、关键数据几何、文件结构与第一方导入。可画内的字体、独立编辑和最终PNG导出仍为`NOT_TESTED`，整体可画交付状态为`AWAITING_CANVA_VALIDATION`。

进入可画时先测试代表模块，再按实际全篇长宽比建立单页连续长画布。直接 SVG 导入如果不能满足文字编辑要求，可以按对象拆分素材并建立可画原生文字，或测试“SVG → 原生 PPTX → 可画”的导入适配。母版可编辑与可画内可编辑分别记录，不能把上传成功当成全部对象可编辑。

## 核心规则

- 先明确中心判断，再安排文案和图表；区分来源事实、计算结果与编辑推断。
- 每张图采用明确且可比较的统计口径，核心数据必须可追溯。
- 当前现象优先使用近 1–2 年数据；官方数据滞后时说明实际年份与发布时间。
- 视觉制作先锁定全篇风格；数字、单位、年份和来源逐项核验。
- 长图最终为一张连续图片，优先使用 2160px 宽母版，并完成概览、100% 和 200% 检查。
- 长图不使用 Word 排版或 PDF 中转；进入可画前先完成代表模块的导入、编辑和导出验证。

## 能力依赖

这份 Skill 提供工作方法，不会随安装自动开通外部工具或服务。

- 资料研究需要可用的网页检索、来源访问或用户提供的资料。
- 原版视觉流程指定使用 **Image-2**。若运行环境无法提供或确认这个模型，应明确报告并暂停依赖它的视觉生成，不能静默改用其他模型。
- SVG 编排由 Codex 建立真实对象；复杂 AI 插画可以保留为位图，文字和精确数据图形需要独立重建。
- 可画中国版与国际版分别核实登录、导入和导出能力。可画导入后的编辑能力尚待当次账号实测，本仓库不宣称平台导入已普遍验证。
- 原生 PPTX 适配可以使用独立安装的 PPT master 或其他经过验证的导出方法。本 Skill 不包含 PPT master 引擎，也不承诺安装后自动提供转换器。
- 正式长图需要支持真实文字、精确定位、连续画布和高清 PNG 导出的工具或渲染流程。
- 网页/H5 成品需要实际的开发、预览和交互验证能力。

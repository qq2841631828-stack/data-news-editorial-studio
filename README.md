# 数据叙事

`data-story-studio` 是用于 Codex 的中文数据新闻 Skill，当前版本为 **3.2.0**。旧标识为 `data-news-editorial-studio`；仓库链接保持不变，安装子目录改为 `skills/data-story-studio`。

它把选题、来源核验、叙事、视觉设计和交付检查组织为可复用流程，支持连续长图、大海报及网页/H5；网页交互仍需单独开发和测试。

新建长图与海报强制采用 **Image-2 完整模块设计 → 同构图 SVG 真实文字与数据对象重建 → 可画实际编辑与导出检查**。只生成装饰插画、套默认图表模板、把 PNG 包进 SVG 都不满足要求。用户明确指定其他制作方式，或只调整已有可编辑作品时，按当前请求执行。

## v3.2.0 验证与发布范围

2026-10-09，仓库所有者明确同意按当前验证范围更新 Skill。代表模块已经真实使用 Image-2 设计、重建 SVG/原生 PPTX 并自动导入可画。测试实际修改并恢复了标题文字、数据标签和图形位置。旧版标题压住复杂背景，被判定为视觉失败；修正版清理标题附近树叶、收小标题、扩大净空，在可画映射为思源宋体并检查了标题避让。

**这不等于完整交付验收通过。** 可画显示高清 PNG 导出完成，但下载文件未完整取回，最终导出图的100%/200%检查仍未完成；插画独立移动、图形试色也尚未测试。修正版保持 `AWAITING_FINAL_EXPORT_VALIDATION`。本次发布的是约束和已记录验证边界的方法更新，不把未测能力写成 PASS。

[代表模块与测试记录](examples/layout-first-v320/README.md)。每次正式制作仍须按实际作品完成验收，不沿用这张代表模块的结论。

## 使用

```text
使用 $data-story-studio，围绕我提供的主题和资料制作一张完整数据新闻长图。
先核验来源和口径，用 Image-2 设计完整模块，再重建为可编辑 SVG，
导入可画并检查字体、独立编辑、图表比例、文字背景避让和最终高清导出。
```

也可用于审核已有数据新闻的来源、时效、叙事和图表表达。

## 新增排版约束

- 标题、正文、数字和单位必须落在连续、安静的底色上；复杂背景打断笔画即返工，不能只换文字颜色。
- 同列文字共用对齐线；单位紧邻数字右侧并共用基线。
- 增长率放在图旁干净留白，避免图上方文字拥挤。
- 环形图标题居中，内圈文字留足边距；柱高、水平线、圆形在导入后复核比例和形状。
- 核对实际中文字体和字重，不能仅凭字体名称认定无替换。
- 概览、100%和200%检查都基于实际最终导出；结构、数量、像素尺寸通过不能替代视觉通过。

## 能力依赖与边界

Skill 不会自动开通工具或账号。需要当前环境提供 Image-2、研究来源、SVG/原生对象导出以及可画访问能力。Image-2 不可用或无法确认时，报告阻塞，不静默换模型、用代码插画替代或把提示词当作生成结果。

插画可以保留为位图，文字与精确数据对象独立重建，因此母版是混合 SVG。可画对象独立可编辑不等于数据表联动；需要联动时须单独验证。PPTX 可作为导入适配载体，本仓库不捆绑 PPT master 引擎。长图是连续画布，不用 Word/PDF 中转或分页 PPT 代替。

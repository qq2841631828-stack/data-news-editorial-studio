# Image-2 完整模块设计与标题避让测试

这是一张1024×1536工作画布的完整代表模块，全部数值为演示数据，用于测试生产路线，不是真实新闻，也不是整篇超长长图。

- [可画设计](https://www.canva.cn/design/DAHXUxbn3Is/qYgDlJtH2HaEcpc7DvzACw/edit)（访问由所有者账号权限决定）

先生成完整设计，再用 Image-2 清稿，重建29个真实文字对象、11个精确形状和1个独立图片层。柱形100与160的高度比为1.6，三组数字单位基线一致。通过原生PPTX适配自动导入可画。

实测改字、改数、移动图形并恢复原值。发现 Noto Serif SC 导入后映射为 Noto Serif，中文回退；在实际可画中改用思源宋体。旧稿标题压在树叶与窗框上，被用户指出后判为 VISUAL_QA_FAILED，未作为通过依据。

针对问题，用 Image-2 定向清除标题附近树叶，并收小标题、扩大留白，生成v2混合SVG和原生PPTX后导入替换测试页。实际编辑器检查了标题避让。导出界面显示2160×3240 PNG已完成，但工具下载失败，最终PNG像素和100%/200%视觉未验收；插画独立移动和试色也未完成。状态保持 AWAITING_FINAL_EXPORT_VALIDATION。

2026-10-09，用户明确同意按此验证范围发布Skill约束更新。未测项不转为PASS，后续正式作品仍须完整验收。环形图未出现在本模块，环内留白规则尚未通过此测试验证。

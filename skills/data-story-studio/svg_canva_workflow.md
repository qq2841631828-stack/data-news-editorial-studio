# AI 视觉生成 → SVG 编排 → 可画

本流程用于用户要求 AI 视觉、SVG 编排、可编辑长图或进入可画的作品。目标是保留 AI 的视觉表现，同时让文字、数据和素材具有明确对象边界。数据研究、统计口径、视觉锁定与长图 QA 继续由原规则负责。

## 1. 先定义需要编辑什么

记录目标平台是 `canva.cn` 还是 `canva.com`、成品形态和编辑要求；两者的登录与工具连接分别核实，不能用国际版测试证明中国版可用。用户未说明时，中文“可画”先按 `canva.cn`，编辑目标先按文字和图形独立调整、插画保留图片。

区分三种能力，交付说明逐项写清：

- `SOURCE_EDITABLE`：SVG 源码中的文字、坐标和路径可以修改。
- `CANVA_OBJECT_EDITABLE`：可画中实际存在可单独选择并修改的文字框、形状或图片对象。
- `CANVA_DATA_EDITABLE`：可画中存在可修改数据表并使图形同步更新的原生图表。

SVG 条形可独立调整，不代表图表数据联动；文字转轮廓后可缩放，不代表能修改文案。不要用“全部可编辑”概括这些差别。

## 2. AI 先做视觉，精确内容另建

1. 完成数据表、文案、章节蓝图和 Visual Style Lock。
2. 每个新模块必须使用 Image-2 生成完整设计稿，同时设计标题/正文层级、图表、关键数字、单位、旁注、插画和留白。保存实际图片、提示词和工具记录；仅有生图提示词或几幅装饰插画不算通过。图中文字/数字属于构图参考，不能作为最终事实载体。
3. 逐模块检查构图，记录实际画布、素材边界、位置、层级、文本和数据对象。
4. 按锁定文案和数据表重建文字、坐标轴、柱形、折线、图例、数字与来源；复杂插画保留为独立高清 PNG 图层。

新作品采用完整单模块设计稿再重建；分层素材只用于已确定构图后的清理、补图或拆层。设计稿是构图依据，SVG 是精确内容依据；不得在重建阶段无理由换风格、改文案或套通用排版。禁止一次性生成整张包含大量正文和多幅图表的超长最终稿。

生成图中的文字和数据图形被真实对象替代时，底图需要移除相应内容；不能留下原字再叠新字，或留下旧柱形再遮挡一部分。没有干净底图时，定向编辑生成图或重新生成相应层。

**不得把整张 PNG 嵌入一个 SVG 就称为矢量重建。** 位图轮廓追踪只适合少量装饰，不用于恢复正文、来源、精确图表或复杂照片。

完成重建后逐模块并排对照设计稿，检查主视觉占位、标题层级、文字对齐、数据位置和留白。精确数据引起的柱高/刻度修正可调整，但需保留版式并说明；发现错字、碰撞或不合理留白先修复再导入。

## 3. SVG 母版按对象编排

- 建立完整长图 SVG，记录尺寸、`viewBox` 和各模块起始位置；模块 SVG 可作为内部过程件。优先导出2160px宽母版，工作坐标可使用较小尺寸，但必须记录统一缩放比例并保持数据几何与字体同步缩放。
- 正文、标题、关键数字和来源使用 `<text>` / `<tspan>`，指定字体、字号、基线、换行和字重，不使用图片承载这些文字。
- 数据对象使用 `<rect>`、`<line>`、`<polyline>`、`<path>` 等精确几何；比例与坐标从数据表计算。用户需要数据联动时，另外保存表格并在可画建立原生图表。
- 插画、照片、纹理用独立 `<image>` 或外部素材层；SVG 内包含位图时，称为“混合母版”，不称为纯矢量图。
- 各独立对象或合理编组具有稳定 `id`，例如 `title-01`、`chart-01-bar-a`、`source-01`、`illustration-01`。层级应服务修改与移动，不为追求对象数量乱拆。
- 保留可重建的对象清单，至少包含 id、类型、文案或数据引用、x/y/宽高、字体、颜色、z-order、素材文件和目标可画对象 id（取得后填写）。
- 不依赖脚本、远程字体、`foreignObject` 或外部网页资源作为静态版式。先用简单 SVG 元素、呈现属性和明确坐标建立兼容版本；复杂滤镜、蒙版与渐变需要单项测试。

母版文字保持文本对象。上传资产若必须转轮廓，另导出一个副本，并将需要修改的文案在可画建立原生文字；不覆盖母版或把转轮廓称为文字可编辑。

## 4. 导入前做代表模块测试

在实际账号，用一个有代表性的模块测试：中文标题、两行正文、来源小字、三个不同数值的图形、一个需要独立移动的素材。技术小样若用演示数据，明显标注“演示数据”，不能发布为真实新闻。

优先测试用户指定的 SVG 导入路线。检查上传接受情况、字体替换、文字换行、图形比例、层级、透明度和实际导出尺寸。SVG 配置、文件体积与平台限制按当前官方文档和实际结果记录，不把历史数字写成永久规格。

可画官方说明目前建议 SVG 1.1，并建议展开描边、路径和文本框。因此 SVG 素材上传不能默认等同于原生文字/图表导入。资料入口：

- [可画上传格式和要求](https://www.canva.cn/zh_tw/help/upload-formats-requirements-cn/)
- [可画 SVG 编辑器](https://www.canva.cn/features/svg-editor/)

文档支持上传或工具返回 media_id，只证明素材被接收；不能据此宣布可编辑设计已完成。

## 5. 可画适配

### SVG 素材与可画原生对象

可画把 SVG 作为单个图形处理时，按实际独立编辑需求拆出图形资产导入。正文、标题、标签与来源在可画建立原生文字框；数据联动图表按已核验的数据表建立。按对象清单还原尺寸与层级，避免把每根柱形拆成难以维护的零散资产。

### SVG → 原生 PPTX → 可画

直接 SVG 无法满足用户的文字/对象编辑要求时，可测试原生 PPTX 作为导入适配载体。SVG 仍是编排母版，PPTX 仅负责让文字、形状和图片保留独立对象，最终编辑器仍为可画。

- 有 PPT master 时，使用其 SVG 到原生 PPTX 的受支持导出流程，遵守该技能的完整性检查与所选路线；不修改其引擎，也不复制其引擎文件进本 Skill。
- 没有 PPT master 时，可以使用其他能保持原生文字、形状与图片的导出方法，先做小样；本 Skill 不承诺自动提供转换器。
- 用户要求可画单页长图时，完整SVG对应一张保持相同长宽比的原生PPTX页面。导出工具需要较小物理尺寸时，可以将画布、文字、形状和图片统一等比例缩小，不能拉伸、自动分页、套成16:9或改成演示文稿版式。模块适配只用于内部测试或已说明的平台限制方案。
- 导出后检查 PPTX 的真实文字和独立对象，再导入可画；可画导入后的对象能力仍需重新检查，不能继承 PPTX 的验证结论。
- 检查实际中文字体效果，不能只看字体名称。本次代表小样的 `Noto Serif SC` 被可画替换为 `Noto Serif` 后中文回退，需在可画映射为支持的“思源宋体”；这是该账号的实测结果，不是永久通用映射。调整后复查字重、换行、基线和来源小字，再导出验证。
- 原生数据图表可能被平台转换为图形。需要数据联动时，恢复可画原生图表；若只能独立修改形状，明确记录实际能力。

优先完成用户指定路线。改变会影响最终编辑方式时说明原因和实际验证结果；不能为了导入方便静默交付整页截图或切回其他产品。

## 6. 导入后的真实验证

在设计副本或可恢复的草稿内执行以下修改，再恢复原文案/数据：

1. 修改一个中文标题的两个字，确认它是可编辑文字框而非图片或轮廓。
2. 修改一个图表标签的数值，确认标签可编辑；有数据联动要求时，再修改图表数据表中的值并确认图形同步变化。
3. 单独移动一个图形和一个插画素材，确认不是整页一起移动；恢复原坐标。
4. 调整一种图形颜色，检查其他对象是否被意外改变。
5. 导出代表模块，检查实际像素、来源清晰度、字体和透明度；对照 SVG 母版查看偏移与裁切。
6. 按 `visual_rules.md` 的排版验收逐项检查，在最终导出图上保存证据。水平线核对两端同高，圆形核对宽高等比；不能凭可编辑就接受变形。

每项记录 `PASS`、`FAIL`、`NOT_TESTED` 或 `NOT_REQUESTED`，保留截图、导出文件、设计链接、平台和测试时间。任一用户要求的编辑能力未经验证，该项不能称为完成。临时改字、试色和演示数据不能遗留在正式交付中。

自动上传单独验收：代理实际选择本地文件、平台接收并打开设计才可记录成功。用户手动上传后由代理编辑、导出的结果，只验证后续环节。文件访问权限报错时，记录当前连接浏览器和失败原因，不反复要求用户开启已确认的设置，也不声称完整自动路线已通过。

## 7. 全篇组装与交付

代表模块通过后才批量导入。可画长画布与高清导出满足实际作品时，可以直接在一张连续画布中组装；否则保留可画中的同宽模块，逐个导出、无损纵向组装，并进行全图概览、100% 和 200% 检查。

优先验证单页长画布，不因模块化生产而默认分页。“调整尺寸 → 自定义大小”可用于实际账号探测；创建副本保留已验证短图。当前可画中国版账号已实测 1024×5120 单页、1/1 页数、末端真实文字与数字编辑、实际 2160×10800 PNG 导出，三个区域来源小字清晰；只适用于这次尺寸与设置，不写成平台最大值。

调整画布会触发自动重排，可能裁切全幅图片并拉散文字。本次因此从原短图复制原生对象，按原尺寸与精确坐标重新组装进长画布。正式作品按全篇蓝图编排，每区承担不同叙事；不能通过拉伸一张短图、重复同一数据或重复整张海报代替完整数据新闻。

完整AI专题样例已验证本地1024×5888编排与2160×12420 PNG，单页PPTX统一缩放为约890.435×5120工作像素，含145个真实文字对象与4个独立插画。它的可画导入、字体映射、编辑和导出尚未完成；这些尺寸仅是样例与本地适配结果，不是可画已验证尺寸或平台上限。样例的不同问卷问题不画成漏斗，任务基准各自与人类比较，实验保留不确定性，2030用电标为预测。

交付完整 SVG 母版、素材和对象清单、可画设计链接及实际编辑能力记录、最终一张高清长图。使用过 PPTX 适配载体时一并提供。模块只是可编辑工作材料，不能替代用户要求的完整长图。

无法登录、上传受阻或无法实际验证时，先完成不依赖账号的 SVG 源文件与素材，状态写为 `SOURCE_READY` 或 `AWAITING_CANVA_VALIDATION`；明确仍缺的测试，不声称导入或可画可编辑已经完成。用户另选本地 SVG 交付时，以该交付目标重新验收。

## 8. 工作流变更先测试再发布

修改本 Skill 的生产路线时，先用一张完整代表小样走通实际流程并检查视觉效果，再更新已安装版本和 GitHub 仓库。结构校验、源码可编辑和本地 PPTX 编辑通过，只证明各自阶段；不能代替目标可画账号内的编辑与导出测试。测试阻塞时保留新版草案和结果，已发布、已安装版本继续使用通过验证的旧版。用户明确选择不同验证范围时按其要求执行，并记录实际边界。

# Data News Visual Rules

本文件约束正式视觉成品。数据、口径和叙事先在 `SKILL.md` 对应 Gate 中通过，再进入视觉生产。

## Visual Style Lock

正式出图前先写一份全篇唯一的视觉锁定表，并贯穿初稿、修改、补图和重生成：

| 字段 | 必须锁定的内容 |
|---|---|
| output_mode | `long_infographic`、`poster` 或 `link` |
| canvas | 尺寸、方向、分辨率、色彩空间、导出格式 |
| grid | 安全边距、内容宽度、列数、模块间距、对齐线 |
| background | 主背景色、允许的分区色和纹理强度 |
| palette | 主色、强调色、辅助灰及各自用途 |
| typography | 字体、字重、标题/正文/标签/来源层级、行距 |
| chart_grammar | 线条、柱形、标注、坐标、图例和高亮方式 |
| illustration | 人物、物件、质感、饱和度、光影和构图语言 |
| decoration | 允许的装饰、密度、位置和禁用元素 |
| source_style | 来源位置、字号、颜色和链接/机构写法 |
| prohibited | Dashboard 感、品牌仿冒、题材错配及项目专属禁用项 |

没有锁定表，不开始批量生成。所有模块使用同一份锁定表，不为单个模块临时换一套视觉语言。

## 参考图使用边界

先声明参考图的用途，可为 `FORM_ONLY`、`LAYOUT_ONLY`、`STYLE_ALLOWED`、`CONTENT_REFERENCE` 或其明确组合。

- 用户只用参考图说明“长图是一整张图”时，必须标记为 `FORM_ONLY`。
- `FORM_ONLY` 只允许学习连续纵向阅读、模块组织和交付形态。
- 未获明确许可，不继承参考图的配色、字体、插画、纹理、装饰、文化符号、品牌识别或题材氛围。
- 已有项目 `Visual Style Lock` 的优先级高于后来出现的形式参考。

## 通用编辑设计规则

- 每张图只有一个核心结论，并使用结论式标题。
- 每张图具备必要的口径副标题、数据标签和来源。
- 核心趋势优先折线或面积；排名优先横向条形；占比优先比例条或 100% 堆叠；两组比较优先同尺度成组或镜像表达。
- 异形图只作辅助，不牺牲精确阅读。
- 一张图通常只用一个主色、一个强调色和辅助灰。强调色只服务结论。
- 图表主体应获得足够面积，不能为塞入更多内容而把坐标、标签和来源缩到不可读。
- 禁止 Dashboard、BI 后台、SaaS 指标卡拼贴、PPT 默认图表、仿冒媒体 Logo 或水印。

## 6 套图表母版

### A. 强结论趋势型

用于时间趋势、上涨、下降和拐点。保留单一主趋势，重点标起点、终点、极值和必要拐点；禁止巨大悬浮 KPI 卡或无意义长引线横穿图表。

### B. 排行榜型

用于地区、品类和 Top N。默认横向排序，数值直标条末，Top 1 或 Top 3 可强调，其余弱化；保留真实差距。

### C. 左右镜像对比型

用于男女、城乡或 A/B 组。两侧必须同尺度、同口径、分类一一对应，颜色固定，不拆成互不关联的两张卡。

### D. 占比结构型

用于构成、份额和原因占比。优先比例条、100% 堆叠或简洁小圆环；百分比和类别名称优先于装饰形状。

### E. 原因解释型

用于原因拆解、文本分析和舆情。每项需有量化依据、关键词与解释，不能把编辑概括伪装成统计结果。

### F. 分组关系型

用于收入、学历、职业或多组人群结构。所有组重复同一视觉语法和尺度，不允许每组任意换图型。

## Long Infographic Production / 长图型高清生产规则

### 自动触发

用户选择“长图型”“做成长图”“一张完整长图”或“超长数据新闻”时自动启用本节，无需用户再次提醒。

### 成品定义

长图型的最终成品是**一张从上到下连续阅读的完整长图**。分段只用于内部制作、生成质量和性能控制，不改变交付形态，也不意味着把若干独立海报随意拼接。

### 硬性禁令

1. 禁止一次性让 Image-2 生成含 8–10 张数据图、800–1000 字及全部来源的整张最终稿；超长画布会稀释像素预算并放大文字、数字和细节错误。
2. 禁止用 Word 排版长图，禁止将 Word 作为长图母版，禁止“Word → PDF → 长图 PNG”的反向生产路径。
3. 禁止让图片模型承担大段正文、密集数据标签和来源小字的最终排版。
4. 禁止先做 4–6 张风格各异的独立海报再硬拼。
5. 禁止为了匹配形式参考而覆盖已锁定的项目风格。
6. 当前版本不使用 PDF 作为长图生产中间件或默认交付物。
7. 可画（Canva）尚未被验证为默认长图工具，不能仅凭“成功导入”或“生成了页面”判定可用于正式交付。

### 1. 先完成整篇内容与蓝图

- 在出图前锁定中心判断、完整文案、图表目录、一图一口径映射和阅读顺序。
- 常规专题长图可规划 4–6 个内部模块；模块数量跟随叙事，不为满足整数强拆。
- 先画整张长图蓝图，明确总宽、预计总高、模块起止、章节节奏、过渡区、图表占位和文字层级。
- 8–10 张图、800–1000 字属于高密度长图，必须先做内容密度检查，避免正文、标签和来源被挤压。

### 2. 锁定全篇视觉系统

- 所有模块继承同一 `Visual Style Lock`。
- 重点锁定相同的背景色值、内容宽度、边距、标题层级、主色/强调色、图表语法、插画笔触、来源样式和装饰节奏。
- 后续补图或重生成必须带回完整锁定表和相邻模块的衔接要求。

### 3. 使用 2× 母版和模块化生产

- 最终母版优先为 **2160px 宽**，高度按内容自适应；发布副本可高质量缩至 1080px 宽。
- 内部通常拆为 **4–6 个 2160px 宽的高清模块**，单模块建议约 **2200–2600px 高**。数值是生产建议，可因内容略调，但不得通过压缩字号强塞内容。
- 每一模块都按整张长图中的固定位置设计，必须共享宽度、网格、色彩空间和边缘背景。
- 分段生成的是视觉资产或可控模块，不是最终交付件。

### 4. Image-2 只生成适合它的部分

- 使用 Image-2 生成主题插画、图表视觉底图、纹理和其他高清视觉资产；同一项目使用相同风格描述和参考资产。
- 提示输入必须包含该模块的职责、在全图中的位置、相邻模块关系、锁定配色、插画语言、禁用项和锁定数据。
- 关键数字、标题、正文、数据标签、单位和来源优先在最终连续画布中以真实文字覆盖或重排。
- 发现数字、比例、中文或风格错误时，只返工受影响资产；未经核验的生成图不得进入最终画布。

### 5. 在一张连续画布中排版

- 使用支持可编辑文字、精确坐标和无损导出的连续画布或可控渲染工作流组装全篇；**不得使用 Word**。
- 标题、正文、关键数字、图例、标签和来源保持可编辑，直至最终导出。
- 可使用代码完成数据计算、尺寸校验、文字排版和无损合成，但不可直接交付默认代码图表或 Dashboard 风格成品。
- 先在 2160px 母版完成排版，再从同一母版导出发布副本；不要先做 1080px 再放大。

#### 排版工具准入

- 本规则只锁定能力，不锁定具体软件。候选工具必须支持连续纵向画布、真实可编辑文字、精确定位、统一色值、2160px 宽导出和无损或高质量 PNG 输出。
- 当前不默认使用可画（Canva）。若以后考虑使用，先制作一段具有代表性的模块并完成实际导出测试，核验真实像素尺寸、文字锐度、长画布限制、导入后可编辑性和 100%/200% 清晰度；全部通过后才能用于当次项目。
- “导入成功”“页面数量正确”或编辑器内看起来正常，不能替代最终 PNG 的尺寸和清晰度验收。
- PDF 路径当前搁置，不参与工具比较、长图组装或默认交付。

### 6. 无缝衔接与无损拼接

- 若工具要求分模块画布，所有模块必须同宽、同色彩空间、同缩放比例，并按像素边界无损纵向拼接。
- 拼接处通过连续背景、合理留白、跨区装饰、章节分隔或连续网格自然过渡。
- 不在拼接边缘截断人物、标题、图表标签或关键装饰。
- 禁止可见色差、重复边框、突然改变的边距、字体跳变、背景断层和一像素缝隙。
- 拼接阶段不重复压缩、不用有损截图、不对单个模块做不一致缩放。

### 7. 字号与安全边距

以下尺寸按 1080px 发布宽度评估；2160px 母版使用约 2 倍像素值：

- 总标题建议 72–96px。
- 模块标题建议 36–48px。
- 正文建议 24–28px，行距保证连续阅读。
- 数据标签建议 22–28px。
- 来源备注建议 18–20px，不能小到放大后仍难辨认。
- 左右安全边距建议 60–80px；2160px 母版对应约 120–160px。

字号不得因内容过多而低于可读阈值。优先删减重复文字、调整模块高度或增加模块，而不是缩小来源和标签。

### 8. 强制视觉检查

最终导出后必须完成三层检查：

1. **全图概览**：检查叙事顺序、章节节奏、密度、风格一致性和明显接缝。
2. **100% 原尺寸**：逐模块检查标题、正文、关键数字、图例、数据标签、单位和来源是否清晰、无裁切。
3. **200% 放大**：检查细字边缘、数字、标点、图表线条、插画细节、压缩伪影、色差与拼接边界。

只有标题、正文、数据标签和来源全部清晰，锁定数据逐项一致，且无明显接缝，才能标记 `VISUAL_QA_PASS`。

## Image-2 生成后的逐项核验

每个资产检查：

- 数字、年份、单位、百分比、排序和比例是否与锁定数据一致。
- 中文是否完整、无乱码、无误字；关键文字是否已改为真实排版文字。
- 结论是否与视觉高亮一致。
- 是否遵守母版和 `Visual Style Lock`。
- 是否出现 Logo、水印、品牌仿冒、Dashboard 卡片或无意义装饰。

任一项失败，状态标记为 `IMAGE_DATA_VALIDATION_FAILED` 或 `VISUAL_QA_FAILED`，不得交付。
